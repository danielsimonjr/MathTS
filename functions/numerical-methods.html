Numerical Methods (47)

Root-finding, optimization, linear systems, and differential equations.

solveDAE
Semi-explicit index-1 DAE y' = f(t,y,z), 0 = g(t,y,z) via variable-step BDF(1–2) with a coupled Newton solve for (y,z) each step; consistent-z0 solve; returns { t, y[t], z[t] } (higher-index input detected via singular ∂g/∂z)
Syntax
solveDAE(f, g, tspan, y0[, z0][, opts])
solveDDE
Constant-delay DDE y'(t) = f(t, y(t), [y(t−τ₁), …]) via the method of steps: adaptive BS23 + cubic-Hermite continuous extension (dense output), step capped at min(τ) so delayed args lie in computed history; lands on t0 + kτ breakpoints; history is φ(t) (or a constant), delays an array of positive τ; returns { t, y[t], yInterp }
Syntax
solveDDE(f, tspan, history, delays[, opts])
