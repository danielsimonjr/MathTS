# @danielsimonjr/mathts-core API Reference

The core package provides fundamental types and utilities for MathTS.

> For the complete, always-current list of every export, see the
> [Complete export index](#complete-export-index) below (generated by

## Installation

```bash
npm install @danielsimonjr/mathts-core
```

## Types

### Complex

Complex numbers with real and imaginary parts.

```typescript
import { Complex, I, COMPLEX_ZERO, COMPLEX_ONE } from '@danielsimonjr/mathts-core';
```

#### Constructor

```typescript
new Complex(re: number, im: number)
```

#### Static Methods

| Method       | Signature                               | Description              |
| ------------ | --------------------------------------- | ------------------------ |
| `fromNumber` | `(n: number) => Complex`                | Create from real number  |
| `fromPolar`  | `(r: number, theta: number) => Complex` | Create from polar form   |
| `parse`      | `(str: string) => Complex`              | Parse string like "3+4i" |

#### Instance Properties

| Property | Type     | Description    |
| -------- | -------- | -------------- |
| `re`     | `number` | Real part      |
| `im`     | `number` | Imaginary part |

Complex exposes dozens of instance methods (trig, hyperbolic, and transcendental operations) plus static helpers such as `compare`, `fromJSON`, `fromNumber`, `fromPolar`, and `parse`.

#### Instance Methods

| Method      | Signature                           | Description                 |
| ----------- | ----------------------------------- | --------------------------- |
| `add`       | `(other: Complex) => Complex`       | Addition                    |
| `subtract`  | `(other: Complex) => Complex`       | Subtraction                 |
| `multiply`  | `(other: Complex) => Complex`       | Multiplication              |
| `divide`    | `(other: Complex) => Complex`       | Division                    |
| `abs`       | `() => number`                      | Magnitude (modulus)         |
| `arg`       | `() => number`                      | Argument (phase) in radians |
| `conjugate` | `() => Complex`                     | Complex conjugate           |
| `negate`    | `() => Complex`                     | Negation                    |
| `inverse`   | `() => Complex`                     | Multiplicative inverse      |
| `sqrt`      | `() => Complex`                     | Square root                 |
| `exp`       | `() => Complex`                     | Exponential                 |
| `log`       | `() => Complex`                     | Natural logarithm           |
| `pow`       | `(n: number \| Complex) => Complex` | Power                       |
| `sin`       | `() => Complex`                     | Sine                        |
| `cos`       | `() => Complex`                     | Cosine                      |
| `tan`       | `() => Complex`                     | Tangent                     |
| `equals`    | `(other: Complex) => boolean`       | Equality check              |
| `toString`  | `() => string`                      | String representation       |

#### Constants

| Constant       | Value           | Description    |
| -------------- | --------------- | -------------- |
| `I`            | `Complex(0, 1)` | Imaginary unit |
| `COMPLEX_ZERO` | `Complex(0, 0)` | Zero           |
| `COMPLEX_ONE`  | `Complex(1, 0)` | One            |

#### Example

```typescript
import { Complex, I } from '@danielsimonjr/mathts-core';

const z = new Complex(3, 4);
console.log(z.abs()); // 5
console.log(z.arg()); // 0.9272952180016122

const w = z.multiply(I); // Complex(-4, 3)
const sum = z.add(w); // Complex(-1, 7)

const parsed = Complex.parse('2+3i');
console.log(parsed.re, parsed.im); // 2, 3
```

### Fraction

Exact rational numbers using bigint for perfect precision.

```typescript
import { Fraction, FRACTION_ZERO, FRACTION_ONE } from '@danielsimonjr/mathts-core';
```

#### Constructor

```typescript
new Fraction(numerator: number | bigint, denominator: number | bigint)
```

#### Static Methods

| Method       | Signature                                          | Description                                                   |
| ------------ | -------------------------------------------------- | ------------------------------------------------------------- |
| `fromNumber` | `(n: number, maxDenominator?: bigint) => Fraction` | Approximate from decimal (default max denominator `1000000n`) |
| `parse`      | `(str: string) => Fraction`                        | Parse "1/2" or "0.5"                                          |

#### Instance Properties

| Property      | Type     | Description                   |
| ------------- | -------- | ----------------------------- |
| `numerator`   | `bigint` | Numerator (always simplified) |
| `denominator` | `bigint` | Denominator (always positive) |

#### Instance Methods

| Method      | Signature                       | Description                |
| ----------- | ------------------------------- | -------------------------- |
| `add`       | `(other: Fraction) => Fraction` | Addition                   |
| `subtract`  | `(other: Fraction) => Fraction` | Subtraction                |
| `multiply`  | `(other: Fraction) => Fraction` | Multiplication             |
| `divide`    | `(other: Fraction) => Fraction` | Division                   |
| `negate`    | `() => Fraction`                | Negation                   |
| `inverse`   | `() => Fraction`                | Reciprocal                 |
| `abs`       | `() => Fraction`                | Absolute value             |
| `pow`       | `(n: number) => Fraction`       | Integer power              |
| `valueOf`   | `() => number`                  | Convert to number          |
| `equals`    | `(other: Fraction) => boolean`  | Equality check             |
| `compareTo` | `(other: Fraction) => number`   | Comparison (-1, 0, 1)      |
| `toString`  | `() => string`                  | String "n/d"               |
| `toDecimal` | `(decimals?: number) => string` | Fixed-point decimal string |

#### Constants

| Constant        | Value            | Description |
| --------------- | ---------------- | ----------- |
| `FRACTION_ZERO` | `Fraction(0, 1)` | Zero        |
| `FRACTION_ONE`  | `Fraction(1, 1)` | One         |

#### Example

```typescript
import { Fraction } from '@danielsimonjr/mathts-core';

const half = new Fraction(1, 2);
const third = new Fraction(1, 3);

const sum = half.add(third); // Fraction(5, 6)
console.log(sum.toString()); // "5/6"
console.log(sum.valueOf()); // 0.8333...

const fromDecimal = Fraction.fromNumber(0.125);
console.log(fromDecimal.toString()); // "1/8"
```

```typescript
import { BigNumber, BIGNUMBER_PI } from '@danielsimonjr/mathts-core';

// No floating point errors
const a = BigNumber.parse('0.1');
const b = BigNumber.parse('0.2');
const sum = a.add(b);
console.log(sum.toString()); // "0.3" (exact)

// Configure precision (does not rebuild named constants)
BigNumber.config({ precision: 100 });
console.log(BIGNUMBER_PI.toString()); // same fixed literal as before config()
```

## mathTyped

The typed-function system for polymorphic dispatch.

```typescript
import { Complex, mathTyped } from '@danielsimonjr/mathts-core';

const myAdd = mathTyped('myAdd', {
  'number, number': (a, b) => a + b,
  'Complex, Complex': (a, b) => a.add(b),
});

myAdd(1, 2); // 3
myAdd(new Complex(1, 2), new Complex(3, 4)); // Complex(4, 6)
```

See [typed-function documentation](https://github.com/josdejong/typed-function) for advanced usage.

## Scalar arithmetic

Polymorphic scalar helpers in `core/src/arithmetic/scalar.ts`: `addScalar`, `subtractScalar`, `multiplyScalar`, `divideScalar`, `pow`, `abs`, `fix`, `round`, `equal`, `isNumeric`, `number`, and type `NumericScalar`. Use `equal(a, b, relTol?, absTol?)` for tolerant comparisons; default tolerances come from `@danielsimonjr/mathts-core/internal` `DEFAULT_CONFIG`, not `MathTSConfig.epsilon`.

## Stable reductions

`pairwiseSum`, `neumaierSum`, `neumaierCumsum`, `norm2`, `pairwiseDot`, `scaledDistance`, and `sumSquaredDeviations` (`core/src/numeric/stable.ts`) provide numerically stable accumulations for large arrays.

## Range

`Range` / `createRangeClass` model `start` / `end` / `step` index ranges with `toArray`, `map`, `forEach`, and `toJSON` (`RangeJSON`). See [Class reference — Range](../reference/classes.md#range).

## Units and exact scales

Beyond `Unit` and `BASE_UNITS`, core exports exact rational scales and SI dimension vectors: type `ExactScale`, plus value exports such as `UNIT_EXACT_SCALE`, `PI_EXACT_SCALE`, `NAMED_IRRATIONALS`, `NAMED_SCALES`, `UNIT_ROWS`, `getUnitRow`, `toSiDimensionVector` / `fromSiDimensionVector`, `SI_DIMENSION_LENGTH` (7), `UNIT_DIMENSION_LENGTH` (10), prefix helpers, and related `*ExactScale` combinators. Re-exported from `@danielsimonjr/mathts-units`.

`SiDimensionVector` is a readonly 7-tuple of `Fraction` exponents in BIPM order `[L, M, T, I, Θ, N, J]`. `toSiDimensionVector` builds exact rationals (`new Fraction(n, 1n)` for integers, `Fraction.fromNumber` otherwise with default `maxDenominator` `1000000n`). `Unit.dimensions` stays `number[]`; pass a 7-vector through `fromSiDimensionVector`, or read numeric components with `vec.map((f) => f.toNumber())` after `toSiDimensionVector` (there is no `toSiDimensionNumbers` helper).

```ts
import { Unit, toSiDimensionVector, fromSiDimensionVector } from '@danielsimonjr/mathts-core';
const si = toSiDimensionVector(new Unit(1, 'N').dimensions);
const nums = si.map((f) => f.toNumber()); // [1, 1, -2, 0, 0, 0, 0]
fromSiDimensionVector(nums); // length-10 Unit exponent vector
```

## Dual unary rules

`DUAL_UNARY_RULES` and type `DualUnaryRule` describe elementary unary ops used internally when you call public `Dual` methods such as `sin()` (`core/src/types/dual-rules.ts`). The `unary` helper is private and not part of the published API.
