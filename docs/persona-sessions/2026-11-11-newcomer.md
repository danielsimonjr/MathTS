I have never used MathTS. I did not build the monorepo. I made a fresh ESM
project at `/tmp/mathts-newcomer` on Node v22.23.4 (TypeScript 7.0.2, `strict`,

find of TypeDoc/API docs.

## Goal

Follow each package’s npm README top to bottom, run every code sample as
written, and notice when README, `exports`, `.d.ts`, and runtime disagree.
Also: which package do I install for X? What error do I see? Do links work?
Are LICENSE / repository / homepage present? Can I get started from the root
README?

## Getting-started path (root README)

Runtime of the four Quick Start / loadWasm fences **passes** if I already
installed every package the snippets import:

- (a) `create(all)` → `math.add(1,2)===3`, `evaluate('sin(pi/2)')===1`,
  `evaluate('x^2 + y', {x:3,y:4})===13`.
- (b) `add` / `Complex` / `Fraction` / `BigNumber.parse` / `evaluate('2^10')===1024`.
- (c) `computePool.initialize` / `sum` / `matmul` / `terminate` (2×2).
- (d) `erfinv(0.5)≈0.476936276`, `wigner3j≈-0.577350269`, `modPow` matches,
  `zeckendorf(100)===[89,8,3]`, `realRoots` ≈ `[1,2,3]` not exact integers
  (README says ≈).
- `await loadWasm()` returns (does not throw).

**Compile:** (a) fails under strict TS: `math.evaluate` is `unknown` (#737).
I could not comment on #737 (403).

Installation still tells me to install **parser** and **evaluator** for
parse/evaluate. Those packages do not export `parse`/`evaluate`. That is
[#796](https://github.com/danielsimonjr/MathTS/issues/796) (related #715).

Signal is advertised for **FFT**; it does not export `fft` (#774).

## Verdict

If I already have **functions + compat + matrix + parallel** and I paste the
**root** README, numbers come out. The **npm package READMEs** are not a
getting-started path: half have no sample, parser/evaluator/signal/linalg/tensor
do not do what the root install table implies, the public function site is a
version behind, and there is no TypeDoc. Workbook and plot (SVG) were the
clearest consumer docs I found.
