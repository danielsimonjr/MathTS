funm
General matrix function f(A) returning a complex-valued matrix { re, im } — diagonal fast path, Lagrange-Sylvester interpolation for distinct eigenvalues, and confluent Hermite interpolation (Newton divided differences over repeated nodes) for defective/repeated-eigenvalue matrices. Defective matrices need derivatives of f: supply them analytically via optional fDerivs (fDerivs[k] = f^(k+1), machine precision) or they are approximated numerically (~1e-6). Throws only when f/a derivative is singular at a repeated eigenvalue (e.g. sqrt/log at 0)
Syntax
funm(A, f, fDerivs?)
