Signal Processing (103)

parallelFFT, parallelIFFT, parallelConv, and related parallel* helpers may return a Promise, but FFT/conv op thresholds in ComputePool are 'never' today — they run the sequential radix-2 / FFT convolution core inline unless a future threshold retune enables workers. Optional WebGPU FFT (enableGpu(), power-of-two n ≥ 262 144) is separate from the worker pool.
