symbolicIntegral
Recursive symbolic antiderivative (power rule, linearity, 1/x, linear-substitution of sin/cos/exp/ln/sinh/cosh), complete rational-function integration (any p(x)/q(x) whose denominator factors over ℚ into linear + irreducible-quadratic factors → rational part + log + arctan, e.g. 1/(x^2+1) → atan(x), (3x+2)/(x^2+1) → (3/2)log(x^2+1)+2·atan(x), repeated factors and improper inputs handled; positive-discriminant quadratic denominators integrate to real logs with quadratic-surd coefficients, e.g. 1/(x^2-2) → `√2/4·log
