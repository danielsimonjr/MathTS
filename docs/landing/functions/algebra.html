factor
Factor completely into irreducibles over ℤ/ℚ, both univariate and multivariate. Univariate via the Zassenhaus algorithm (x^4-1 → (x-1)*(x+1)*(x^2+1); ℚ-irreducibles like x^4+1 returned unchanged). Multivariate via Kronecker substitution onto the univariate engine (x^2-y^2 → (x-y)*(x+y), (x+y+1)(x+2y+3) expanded → its two linear factors, (x+y)^2*(x+2y)), with the content/common-monomial/difference-of-squares fast path preserved for the cases it already handled. Bounded by a substituted-degree cap (Wang/EEZ is the future performance upgrade for very high-degree many-variable inputs)
Syntax
factor(expr)
