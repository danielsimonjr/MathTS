# Oracle Coverage Matrix

> **What this is.** A per-domain matrix of which public typed functions are verified
> against an **external oracle** (pinned reference values from SciPy / NumPy / mpmath /
> DLMF / Abramowitz&Stegun, or a mathematically-independent closed form) versus those
> tested only **self-referentially** (against MathTS's own output, trivial round-trips,
> or loose hand-typed sanity checks with no external grounding).
>
> **Why it matters.** Line coverage is ~97.5% effective, but that says nothing about
> *numerical correctness*. This matrix is the WS-1 **Phase-1** deliverable and the
> work-list for WS-1 **Phase-2** (adding oracle pins). See
> `docs/roadmap/SCIENTIFIC_LIBRARY_ROADMAP_2026-07-02.md` (WS-1).
>
> **Generated by:** read-only audit, 2026-07-02 (five parallel passes over
> `functions/src/typed/*.ts`, the `functions/src/*-extra.ts` gap-closure files,
> `functions/src/distribution-functions.ts`, and `matrix/src/{operations,decomposition}/*`,
> cross-referenced against the test suites under `functions/tests/`, `matrix/tests/`).

## Classification

| Class | Meaning |
|---|---|
| **ORACLE(ext)** | A test pins the result to an **external** reference — a comment citing scipy/numpy/mpmath/DLMF/A&S plus a multi-digit decimal constant. Strongest grounding. |
| **ORACLE(cf)** | A test pins to a genuine **closed-form / exact mathematical identity** verified independently of the implementation (e.g. `gcd(12,8)=4`, `hypot(3,4)=5`, `beta(2,3)=1/12`, Rosenbrock minimum at `(1,1)`, Bézout `a·x+b·y=gcd`, an analytically-known eigenvalue). Correctness is established without an external tool. |
| **SELF-REF** | Grounded only by comparison to MathTS's own output (incl. the JS `Math.*` primitive the impl itself calls), a round-trip (`fft`→`ifft`), a decomposition reconstruction (`Q·R≈A`), orthogonality/monotonicity/shape sanity, or directional thresholds (`p<0.05`). A systematically-biased implementation could pass these. |
| **UNTESTED** | No test references the function. |

> Both **ORACLE(ext)** and **ORACLE(cf)** count as "oracle-verified" in the summary; the
> sub-tag records *how* strongly. A decomposition **reconstruction** check (`A=Q·R`,
> `P·A=L·U`, `A·inv(A)=I`) is **SELF-REF**, not oracle — it is self-consistency, not
> ground truth. Where a domain was sampled rather than exhaustively enumerated, it is
> stated in that section.

**Headline findings**

- **Special functions (38/38)** and **Distributions (46/46)** are the *best* covered — the
  `gap-wave-*` files pin them to SciPy/mpmath/DLMF constants. `gammaQuantile` and
  `betaQuantile` were the only outright UNTESTED functions; **both were pinned in WS-1 P2**
  (`functions/tests/gap-quantile-oracle.test.ts`) — the matrix now has **0 UNTESTED**.
- **Arithmetic, Trigonometry, typed Statistics** carry **zero external pins** — they rest
  on closed-form identities (fine for elementary algebra) or, for trig, on the JS `Math.*`
  primitive the implementation itself calls (tautological on the `number` path).
- **The 7 core `hypothesis.ts` tests are purely self-referential** — no p-value or
  statistic is pinned to SciPy (only directional `p<0.05`). This is the single biggest
  correctness gap by leverage, and the `hypothesis-extra.ts` siblings already show the
  scipy-pin pattern.
- **10 linalg decompositions are verified only by reconstruction/round-trip** (`qr`, `lu`,
  `matrixSchur`, `hessenbergForm`, `polarDecomposition`, `qz`, WASM `inv`, `svdWasm`,
  svd-`pinv`, `lowRankApprox`) — no pinned eigenvalues/singular-values/factor entries.

## Recommended Phase-2 priority

Favoring the highest-leverage numerical surfaces (special functions, decompositions,
distribution CDF/quantiles). Ordered by value:

### Tier 1 — highest value

1. **Decomposition factor/value pins.** `qr`, `lu`, `hessenbergForm`,
   `polarDecomposition`, `qz`, WASMBackend `inv`, `svdWasm`, svd-`pinv`, `lowRankApprox`
   are verified **only by reconstruction/orthogonality** — a systematically-biased
   factorization passes today. Pin the classic Householder `R`
   (`[[12,−51,4]…]` → R=[[14,21,−14],[0,175,−70],[0,0,35]]), the exact `L`/`U`, and a
   known analytical `inv`. (`matrixSchur` is now done — see below.)

   > **🐞 `matrixSchur` — two bugs surfaced AND FIXED by the WS-1 P2 eigenvalue oracle**
   > (`matrix/tests/operations/schur-eigenvalue-oracle.test.ts`). **(1)** real 2×2 diagonal
   > blocks were accepted unreduced (as if complex pairs), so eigenvalues read off `T` were
   > wrong — fixed with `standardize2x2Block`. **(2)** the Francis double-shift **stalled**
   > when eigenvalues are symmetric about the shift centre (e.g. tridiagonal Toeplitz
   > `{4−√2,4,4+√2}` returned unchanged) — fixed with an **exceptional shift**
   > (`qrStepSingleShift` + `exceptionalShift`, every 10 stalled sweeps). Reconstruction-only
   > tests were blind to both. Verified by a 6-case eigenvalue oracle + full matrix suite
   > (749✓/7skip). `matrixSchur` is now **ORACLE**.
2. ~~**`gammaQuantile` and `betaQuantile` — UNTESTED.**~~ ✅ **DONE (WS-1 P2)** —
   `functions/tests/gap-quantile-oracle.test.ts` pins both to chi-square-table + exact
   closed-form oracles (uniform, exponential, `Beta(a,1)=p^(1/a)`, symmetric-median);
   both were already correct (7/7 GREEN, no source change). Remaining: promote the
   factory `gammaDist.quantile` / `betaDist.quantile` self-ref inversions to external pins.
3. **The core `hypothesis.ts` statistics/p-values.** ✅ `studentTTest` + `anova` +
   `chiSquareTest` + `mannWhitneyTest` **DONE (WS-1 P2)** —
   plus `principalComponentAnalysis` — `functions/tests/gap-hypothesis-oracle.test.ts`
   pins exact statistics + closed-form p-values (ANOVA, χ²₂) + critical-value brackets +
   a known-covariance PCA spectrum (6/6 GREEN, all already correct). Remaining (2):
   `kolmogorovSmirnovTest` (pin deterministic `D`), `shapiroWilkTest` (Royston `W` —
   needs a scipy reference).
