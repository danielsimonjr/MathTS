## Getting Help

### GitHub Discussions

For questions, ideas, and general discussions, please use [GitHub Discussions](https://github.com/danielsimonjr/mathts/discussions):

- **Q&A** - Ask questions about using MathTS
- **Ideas** - Share feature ideas and suggestions
- **Show and Tell** - Share what you've built with MathTS

### Stack Overflow

For technical questions, you can also ask on [Stack Overflow](https://stackoverflow.com/questions/tagged/mathts) using the `mathts` tag.

### Bug Reports

If you've found a bug, please [open an issue](https://github.com/danielsimonjr/mathts/issues/new?template=bug_report.md) with:

- A clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Your environment (MathTS version, Node.js version, OS)

### Feature Requests

Have an idea for a new feature? [Open a feature request](https://github.com/danielsimonjr/mathts/issues/new?template=feature_request.md) and describe:

- The problem you're trying to solve
- Your proposed solution
- Any alternatives you've considered

## Security Issues

For security vulnerabilities, please **do not** open a public issue. Instead, follow our [Security Policy](./SECURITY.md) and report privately.
