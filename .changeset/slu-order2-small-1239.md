`slu(A, 2, threshold)` factorizes a square sparse matrix that has a dense row (Fixes #1239). `csAmd` drops each row with more than `min(n - 2, max(16, 10 * sqrt(n)))` entries: most 1x1 to 4x4 matrices have such a row, and so does a matrix of any size with a full row. `csAmd` drops the dense columns of the transpose in place, but left the dropped entries in the index and value arrays. The next transpose then counted them and built corrupt column pointers, and the product `A' * A` threw `TypeError: Cannot set properties of undefined`. `csAmd` now truncates both arrays after the compaction. Results on main before this change, order 2 and threshold 0.001: 1x1 `[[4]]`, 2x2 `[[4,3],[6,3]]`, 2x2 identity, 3x3 `[[2,1,0],[1,3,1],[0,1,4]]` and a full 6x6 threw `setting '0'`; a 4x4 tridiagonal threw `setting '1'`; a 5x5 tridiagonal and a 6x6 diagonal already factorized and give the same result. A diagonal matrix with one full row threw at each size from 5x5 to 200x200. The ordering of each case in this list equals the mathjs 15.2.0 result. A singular matrix with a dense row now throws the singular-matrix `Error` at order 2.

The sparse `transpose` now counts only the entries that the column pointers reach (`ptr[columns]`), not every entry of the index array. A matrix with stale entries after the last column pointer now transposes correctly.
