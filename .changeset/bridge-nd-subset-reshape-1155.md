`subset`, `reshape` and `resize` of a dense matrix read every axis, not the first two. A scalar index drops its axis, so `subset(d3, index(1, 0, 1))` is a number and `subset(d3, index(0, [0, 1], 1))` has size [2]. A wrong number of indices throws the mathjs `DimensionError`, and an index out of range throws an `IndexError`. `subset` assignment writes every selected entry of a 3-D matrix, broadcasts a replacement to the shape of the selection, and gives a replacement with fewer axes the missing axes of length 1 (the mathjs `_set` rule). One selected entry takes one value only (`Scalar expected`). An assignment after the end of an axis grows the matrix and fills the new entries with the default value, a negative or non-integer index throws, and `get` checks each index. The `reshape` method changes its matrix and returns it, as in mathjs; the sparse matrix has a `reshape` method. `diag` of a 1-D matrix puts numbers on the diagonal. `reshape` of a matrix with three or more axes keeps the values, and a size with the wrong number of entries throws `Dimension mismatch`. A `subset` assignment does not change the replacement Array of the caller. (Refs #1155)
