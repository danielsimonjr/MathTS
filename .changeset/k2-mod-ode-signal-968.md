The typed `floor`, `ceil`, `fix` and `mod` follow mathjs 15.2.0. `floor(2.9999999999999996)` is 3 and was 2. `ceil`, `fix` and the BigNumber rows snap to the nearest integer in the same way, with the live `relTol` and `absTol`. `mod(0.3, 0.1)` is `-5.551115123125783e-17` and `mod(0, -4)` is `0`. Two integers still give the exact remainder, so `mod(1700006399999, 86400000)` is 86399999 (mathjs gives -1). The factory `mod` uses the same function. `compat` and `evaluate` take the new results. `add`, `subtract` and `multiply` of an Array and a matrix, and `add` and `subtract` of a dense and a sparse matrix, return a `DenseMatrix` (a `SparseMatrix` for a 2-D Array times a sparse matrix), and returned an Array. The generated `PublicAdd` type follows. `csd` and `coherence` take a segment of exactly `nperseg` points and no longer pad it to a power of two. `csd` is a one-sided density: the bins between DC and Nyquist double, so `csd(x, x)` equals `welchPSD(x)`. `sampleN` rejects a count that is not a non-negative integer, and a count above 100000000, with a `RangeError` before it allocates. A Bluestein transform (a length that is not a power of two) keeps its chirp and filter spectrum for the next call of the same length: 1.3 to 1.6 times faster for a repeated length. The step-limit error of `solveODE` names stiffness only when the stability limit of the method, and not the tolerance, ends the run. A BigNumber derivative that is not finite stops the run at once. (Refs #968)
