`pow`, `sqrtm`, `expm`, `sylvester` and `kron` handle empty matrices (Refs #1233). A 0 x 0 input gives a 0 x 0 result of the same container type, as `inv` and `det` do (#1230). `pow(A0, 0)` is the 0 x 0 identity. mathjs 15.2.0 throws for `pow`, `sqrtm`, `expm` and `sylvester` of every 0 x 0 input.

- `pow([], n)` threw `For A^b, A must be 2 dimensional (A has 1 dimensions)` for every `n`. It returns `[]` for an integer `n`. `pow` of `matrix([])`, of a 0 x 0 DenseMatrix and of `sparse([])` threw the same error. They return a 0 x 0 matrix of the same storage (a new object). A non-integer `n` still throws, and so do `[[]]` and `zeros(3, 0)` (`A must be square`).
- `sqrtm([])` returns `[]`. Before, it threw `Matrix must be square (size: [0])`. `sqrtm(matrix([]))` threw the same error and now returns a 0 x 0 DenseMatrix. A 0 x 0 DenseMatrix threw `Cannot calculate max of an empty array`, and `sparse([])` threw `Dimension mismatch (1 != 2)`. They return a 0 x 0 matrix of the same storage. `[[]]` and `zeros(3, 0)` still throw.
- `expm([])` and `expm(sparse([]))` return `[]`. Before, both threw `DenseMatrix nested array must be a non-empty rectangular array of numbers` (a non-empty sparse matrix returns an Array). `expm([[]])` threw the same message; it now throws `matrixExpm: matrix must be square (got 1×0)`. `expm(matrix([]))` and `expm` of a 0 x 0 DenseMatrix already returned a 0 x 0 matrix and are unchanged.
- `sylvester` of a 0 x 0 system threw `schur: matrix must be square (real Schur decomposition)` for every kind. Three Arrays `[]` return `[]`; a Matrix operand gives a 0 x 0 DenseMatrix. When A is m x m and B is n x n with m or n equal to 0, the result is the empty m x n matrix, and a C of another size throws `RangeError: Dimension mismatch`.
- `kron` read the size of a Matrix from `toArray()`, which drops the shape of a matrix with a zero row count. `kron` of two 0 x 0 matrices, or of a 0 x 0 matrix and any 2-D operand, returned a matrix of size `[0]` or `[1, 0]`; it returns a 0 x 0 DenseMatrix. `kron(zeros(0, 2), [[1, 2]])` returned size `[1, 0]` and now returns `[0, 4]`. `kron(zeros(2, 0), zeros(0, 3))` returned `[2, 0]` and now returns `[0, 0]`. The result size is the product of the operand sizes. mathjs 15.2.0 returns the earlier sizes. A one-dimensional empty operand (`[]`, `matrix([])`) is still a vector, so `kron([], [[1, 2]])` is `[[]]`, as before. A sparse operand still gives a DenseMatrix.
