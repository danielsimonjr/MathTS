`eig(A).repeatedEigenvalues` counts a defective eigenvalue as defective when its coupling is below `sqrt(eps) * ||A||_F` (Fixes #1180). The rank tolerance of a cluster was fixed at `sqrt(eps) * ||A||_F`. It is now 4 times the measured cluster radius, between `8 * n * eps * ||A||_F` and the old `sqrt(eps) * ||A||_F`. A singular value above that tolerance counts as a coupling only when it is at least 16 times the largest one below it. Without that second test, rounding noise in a matrix such as `S * (2I) * S^-1` with a graded `S` was reported as a coupling. Value change: `[[1,1e-9],[0,1]]` and `[[1,1e-12],[0,1]]` report 1 independent eigenvector (were 2), and `[[1,1e-9,0],[0,1,0],[0,0,1]]` reports 2 of 3 (was 3). The report no longer reads the `isSymmetric` flag. It treats the matrix as symmetric when every `|a_ij - a_ji|` is at most `8 * n * eps * ||A||_F` (the flag has a looser tolerance, see #1191). A coupling below `8 * n * eps * ||A||_F` (about 6e-15 for a 2 x 2 matrix with unit entries) still counts as zero.
