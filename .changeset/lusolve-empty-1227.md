`lusolve` of an empty system no longer throws "Linear system cannot be solved since matrix is singular". A 0 x 0 system has the empty solution. `lusolve([], [])` returns `[]`. For a `DenseMatrix` or `SparseMatrix` `A` (also with `order` and `threshold`), and for an `lup`/`slu` style factor object with 0 x 0 factors, it returns a 0 x 1 `DenseMatrix`. `lusolve(lup([]), [])` threw `RangeError: Matrix must be two dimensional (size: [0])`, not the singular error; it now returns the same 0 x 1 `DenseMatrix`. The right-hand side can be `[]` or `matrix([])`. An empty input that is not square (`[[]]`, `matrix([[]])`, `sparse([[]])`, factors that are 1 x 0) throws the same dimension error as a non-empty non-square input. A factor object is checked `L` first, then `U`, so `lusolve(lup(zeros(3, 0)), b)` throws the same `Matrix must be square (size: [3, 0])` as before. A ragged Array whose first row is empty (`[[], [1]]`) throws the square-matrix error; it threw `Dimension mismatch`. A right-hand side of the wrong size (for example `[1]`, or a 1 x 0 or 0 x 2 matrix) throws `Dimension mismatch` for every kind of `A`, `[]` included. The non-square error of an Array `A` is a plain `Error`, as for a non-empty Array `A`. Non-empty systems are unchanged.
