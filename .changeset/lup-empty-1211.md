`lup` of an empty matrix returns the factor shapes `L` m x k and `U` k x n (k = min(m, n)), with `p` the identity on the m rows, as `slu` does. `lup(matrix([]))` gave an `L` with size `[0, NaN]` and a `U` with size `[NaN, undefined]`; both are now `[0, 0]`. An input with rows and no columns (`[[]]`, `[[], [], []]`) lost the row count of `L` in `valueOf()` and in the Array result (`L` was `[]`); `L` is now `[[]]` or `[[], [], []]`. `U` of those inputs stays `[]` (0 x 0). Sparse and 0 x n inputs are unchanged. A dense input that is not two-dimensional, other than the empty `[]`, now throws `RangeError: Matrix must be two dimensional (size: ...)`, the error that `det` and `inv` throw for a 3-D input (for a 1-D input they throw `Matrix must be square`). A non-empty 1-D DenseMatrix (`lup(matrix([1, 2]))`) returned `L` of size `[2, NaN]` and `U` of size `[NaN, undefined]`, the Array `lup([1, 2])` returned `{ L: [], U: [], p: [0, 1] }`, and a 3-D input threw an internal `equalScalar` `TypeError`.
